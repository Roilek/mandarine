# Mandarine & Co — site web

Site one-page de Mandarine & Co, agence événementielle à Sion : événements d'entreprise et privés,
location de mobilier avec panier et demande de devis, Selfie Box.

Réalisé par [Opteamize](https://opteamize.ch).

## Fonctionnement

- **Hébergement** : GitHub Pages, gratuit. Toute modification sur la branche `main`
  est en ligne en 1 à 2 minutes.
- **Demandes de devis** : elles ouvrent la messagerie du visiteur, pré-remplie, vers
  info@mandarineandco.ch.
- **Aucun serveur, aucun abonnement.** Le site vous appartient entièrement.

## Modifier le site

Demandez la modification à votre assistant IA (ChatGPT, Claude…) connecté au site, en français
(« change le prix de la table haute », « ajoute une photo de notre dernier événement »…).
Le fichier `AGENTS.md` lui explique comment le site est construit et ce qu'il ne doit pas casser.

Chaque modification est enregistrée : on peut toujours revenir à la version précédente.
